# Demo Outputs

These are sample outputs generated by MoogTestAI's AI agents. They demonstrate what the system produces when given the pilot design documents (MOOG-SA-4200 Servo Amplifier Control Card).

## Files

| File | Agent | Description |
|---|---|---|
| [sample_test_plan.md](sample_test_plan.md) | Test Plan Generator | 15 structured test procedures across 5 categories with specific pass/fail criteria |
| [sample_risk_analysis.md](sample_risk_analysis.md) | Signal Analyzer | FMEA-style analysis with critical signals, key components, and prioritized risk matrix |
| [sample_debug_report.md](sample_debug_report.md) | Debug Agent | Root cause analysis of an overcurrent failure with correlated failures and troubleshooting steps |

## How these were generated

```bash
# 1. Ingest design documents into ChromaDB
python -m src.cli  # Select option 1

# 2. Generate test plan
python -m src.cli  # Select option 2

# 3. Run FMEA analysis  
python -m src.cli  # Select option 3

# 4. Debug test results
python -m src.cli  # Select option 4, then select the overcurrent failure file
```

Each output is generated by combining RAG-retrieved design context (from the actual datasheet, schematic, and BOM) with LLM reasoning to produce domain-specific, actionable results.
