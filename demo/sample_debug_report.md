## 3. Failure Analysis

### 3.1 Cluster: Current Measurement Error (CT-006, CT-007, CT-008)

**What happened**: At the 10A setpoint, both Phase A and Phase B are reading ~11.7% below the expected value (8.83A and 8.79A vs 10.0A). The overcurrent protection, which should trip at 15A, didn't trigger until 16.8A — also approximately 12% higher than designed.

**Root Cause Hypothesis**: The current sense resistor R15 (10mΩ, rated 3W) has likely drifted in value due to thermal stress. A 12% reduction in resistance means the sense voltage at 10A would be 0.88mV instead of 1.0mV, causing the MCU's ADC to read a proportionally lower current. This explains both the low current readings AND the elevated overcurrent threshold — the same measurement error affects both.

**Correlated Evidence**:
- Both phases show nearly identical error (~12%), ruling out a single-channel issue
- The error is consistent across setpoints (appears at 10A but not 5A, suggesting possible nonlinearity from self-heating at higher currents)
- From datasheet: R15 is a 2512-package metal alloy resistor with TCR of ±75 ppm/°C. At elevated temperature (90°C+), resistance could drop by up to 0.5% — but 12% is far beyond TCR drift

**Revised Hypothesis**: The more likely cause is a **solder joint defect** on R15 adding parasitic resistance in series with the sense path, or a **wrong component value** was populated during assembly (e.g., 8.8mΩ instead of 10mΩ).

### 3.2 Thermal Warning Delay (CT-009)

**What happened**: The thermal warning threshold, designed for 85°C ±3°C, didn't trigger until 92°C — a 7°C overshoot.

**Root Cause Hypothesis**: This is a **consequential failure** caused by the current sense error above. Because the board believed it was operating at ~8.8A when actual current was 10A, the extra I²R losses (10² × RDS(on) vs 8.8² × RDS(on) = 29% more power dissipation) caused the board to heat faster than the protection system expected. The thermal sensor itself (U6, TMP235) is likely functioning correctly — the issue is that the board was operating in an unprotected region due to the current measurement error.

### Step 1: Verify R15 Value

- **Equipment**: Keithley 2400 or equivalent 4-wire milliohm meter
- **Expected if hypothesis correct**: Measured value will be ~8.8mΩ instead of 10mΩ
- **Next step**: If value is correct (10mΩ), proceed to Step 2. If wrong, replace and retest.

### Step 2: Check R15 Solder Joints
- **Action**: Inspect R15 solder joints under microscope (20x minimum)
- **Equipment**: Stereo microscope, or X-ray if available
- **Expected if hypothesis correct**: Cold joint, insufficient wetting, or cracked joint on one or both pads
- **Next step**: If joints look good, proceed to Step 3.

### Step 3: Verify ADC Calibration
- **Action**: Inject known voltage (1.00mV) at the current sense input and verify MCU ADC reading
- **Equipment**: Precision voltage source (Keysight 33500B), DMM
- **Expected if hypothesis correct**: ADC reads correctly, confirming the error is in the sense resistor path
- **Next step**: If ADC reads incorrectly, investigate MCU ADC reference voltage.

### Step 4: Re-validate After Fix
- **Action**: After replacing R15, re-run full test suite (CT-001 through CT-012)
- **Equipment**: Full test setup
- **Expected**: All 12 tests pass, thermal warning triggers at 85°C ±3°C

## 5. Recommendations

1. **Assembly Process**: Add current sense resistor value verification as an in-process inspection step. Measure resistance of all 10mΩ sense resistors before and after reflow.

2. **Design Change**: Add a software-based redundant overcurrent check using the bus voltage and gate PWM duty cycle to estimate current independently of the sense resistor.

3. **Test Enhancement**: Add a dedicated current sense accuracy test at 3A, 5A, 8A, 10A, and 12A to catch drift at multiple operating points, not just a single setpoint.

4. **BOM Review**: Verify the current sense resistor P/N on the BOM matches the schematic value. Cross-check with incoming inspection records.
